3. DIALOGUE FLOW (choices + loading + error states)
--------------------------------------------------------------------------------
Click the "Talk to the elder" button (top-left HUD).

Expected:
- The dialogue box appears at the bottom with speaker "Elder". While the AI
  text is being generated, a "thinking" indicator should be visible in the
  box.
- The AI text renders when ready. Because the prompt now asks for it, the
  response should usually include a `[choices]` block, which the app parses
  into numbered option buttons inside the box.
- Clicking an option ends the turn. If no options were offered, "Continue"
  advances and the box stays open until "Leave".
- The "Leave" button is ALWAYS present and ALWAYS ends the interaction
  (always-escape — the player can never get stuck in a dialogue).
- Click "Talk to the elder" again and click "Leave" — the box must close.
- If you can force a text-generation failure (e.g., break the network), an
  error message with retry should appear instead of a silent hang.

Report: does the dialogue open? Is the loading indicator visible during
generation? Does the text render? Do the numbered options appear (and how
often)? Do options work when present? Does "Leave" always close the box?
Any error handling observed?
