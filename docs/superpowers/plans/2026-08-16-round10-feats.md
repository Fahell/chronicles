# Round 10 — Feats Implementation Plan (pause menu, dev inspector, portraits + free-form input)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the round-9 fixes plus three new features in one Perchance round: the in-game pause menu v1 (Esc → Save/Settings/Quit, autosave-slot save, save-before-quit prompt), the dev context inspector v1 (`?inspector=1`), and speaker portraits in the dialogue box (NPC + user, bust, white background, no RMBG, async) with the player's free-form "write your own action" input.

**Architecture:** All three features are Preact UI + game-state additions over the existing services. Portraits are a new asset type in the existing `assets` Dexie table (pose `portrait`, no `removeBackground`) resolved via the `AssetCache`; a `portraitsSignal` (characterId → dataUrl) feeds the dialogue box. The pause menu is a game-screen overlay toggled by Esc (dual behavior with the existing dialogue Esc). The inspector reuses the payload builder — refactored to emit named, summarizable-tagged sections — plus prompt/description/count metadata, gated by the `?inspector=1` URL param.

**Tech Stack:** TypeScript strict, Preact + signals, Dexie (existing `assets` table), Vitest (unit/integration/e2e), Biome. No new dependencies.

## Global Constraints

- No new dependencies. Reuse `AssetCache`, `SaveStore`, i18n `t()`, the dialogue machine.
- i18n: add English keys only; other locales fall back (`i18n.ts` pattern).
- Portraits: **never** set `removeBackground`; prompt requests a **pure white** background; bust crop (head + shoulders); 512×768 resolution; pose `portrait`.
- Portrait generation is **async** (fire-and-forget, never awaited) so it adds zero wait time; the sprite resolve stays the awaited path.
- Re-roll regenerates **sprite + portrait together** (same seed).
- Save from pause writes to the **autosave slot directly** (no picker); manual slots stay wizard-only.
- The inspector is **off by default**, enabled by `?inspector=1`, exists in dev AND prod builds, shows only data payloads already contain.
- Free-form input caps the typed action at 300 chars (protects the context window).
- Player turn display: selected choice / typed action shows as a player turn with the player's portrait (only current speaker's portrait shows).
- Esc handling: dialogue open → closes dialogue (existing, `e.preventDefault()`); no dialogue → toggles pause. The pause handler must check `e.defaultPrevented`.
