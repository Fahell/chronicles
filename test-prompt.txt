# Round 8 — Runtime validation prompt (gameplay phase)

You are validating the latest build of **Chronicles** (a visual-novel RPG built
on this Perchance generator). The app now has an **onboarding flow** (title →
New Game wizard → game), a **world narrator opening**, **multi-turn dialogue**
with the picked NPC, **save slots**, a **fog effect**, and a **sprite re-roll**
button. The background-removal pipeline from the previous rounds is unchanged.

Run the checks below **in order**, driving the actual UI (click, type, observe
the DOM and the console). The AI plugins are real here, so generations take
time — the loading indicators are part of what we validate. Report everything
with **console lines verbatim** (keep the `[rpg]` logs) and your observations.

## 1. Boot & title screen

- Reload. Expect: the **title screen** renders (light paper look, "CHRONICLES"
  title, menu: NEW GAME / LOAD GAME / SETTINGS / CREDITS / HELP).
- **LOAD GAME must be disabled** (greyed, non-clickable) when no save exists
  yet — verify the `aria-disabled` state and that clicking does nothing.
- Keyboard: Arrow keys move the hand pointer between items; Enter/Space
  activate the selected item. Esc does nothing on the title.
- Console: only the favicon 404 and benign plugin warnings are acceptable.

## 2. New Game wizard

- Click **NEW GAME**. Step 1 asks for a **name** — type one (e.g. "Arin").
- **Next** → Step 2 (appearance): click an archetype (Knight / Mage / Rogue /
  Traveler). A **sprite preview should appear** (in prod it is generated by
  the image plugin + client-side removal — this may take ~10-30 s; in dev it
  is a placeholder). Note the corner chip if it appears ("Removing background
  1/1…").
- **Next** → Step 3 (background): pick a template story OR switch to custom
  and type your own. **Next** → Step 4 (review): name, sprite thumbnail, and
  your background story are shown.
- Click **Create**. Expect: a save slot is created and the **game scene
  loads** (loading screen first). The scene shows your character + one NPC on
  a grassy floor with a twilight valley backdrop, plus the **fog effect**
  (subtle drifting haze over the scene frame — verify it animates and that
  the page stays responsive; ~60 fps is expected, not required to measure).
- Console: expect the model/cutout logs as before (`proxy worker active`,
  `model ready`, `cutout-cache: miss <id> → removing`, `queue drained`) and a
  new **narrator generation** (no `[rpg]` log for text — the narrator shows
  as dialogue).

## 3. Narrator opening + dialogue

- After the scene loads, a **dialogue box opens with the Narrator** speaking
  2-3 sentences about the scene. Advance with **Continue** (or Enter), then
  **Leave**.
- Click **Talk to <NPC name>** (top-left HUD). Expect the NPC's reply with
  the **thinking line** first ("<name> is thinking…"). The reply should be in
  character and may include **choices** (buttons).
- **Multi-turn loop (critical):** click one of the choices. Expect the NPC to
  answer the choice and possibly offer **new choices**. The loop continues —
  you can pick again. This is the core new mechanic; test it at least 3
  turns deep.
- **Always-escape (critical):** click **Leave** at any point — including
  WHILE the NPC is thinking — and confirm the box closes and the NPC stops
  responding. Leave must always be present and always work.
- If the NPC reply contains a `[choices]` block, verify the options rendered
  as buttons (not raw text).

## 4. Re-roll sprite

- Click **Re-roll sprite** (HUD). Expect a **new generation** with a new seed
  (console: `cutout-cache: miss <npc id> → removing`, chip 0/1 → 1/1) and the
  NPC's sprite in the scene **changes** (different portrait). Repeat once to
  confirm the button is not sticky and the scene stays stable.

## 5. Reload / save persistence

- Reload the page. Expect the **title screen** again — now **LOAD GAME is
  enabled** (a save exists).
- Click **LOAD GAME**: the save slot shows the player name, "Day 1 · dusk"
  and a date. Click it → the same scene loads with the **same player identity
  and the same NPC** (no re-creation, no new NPC pick; sprite textures from
  cache — `cutout-cache: hit` logs; scene textures from cache too — expect a
  fast load, no regeneration).
- Create a **second new game** (different name/archetype) and confirm it
  creates a second slot. Then try a third; when the 3 manual slots are full,
  a **fourth new game must ask which slot to overwrite** — verify the
  overwrite picker and that choosing a slot replaces that save.
- If a save was created with the wrong NPC/identity, note it.

## 6. Settings & language

- From the title, open **SETTINGS** → **Language** tab. The 5 languages
  (English / Chinese / Hindi / Spanish / Arabic) are listed. Pick **Spanish**
  (or any non-English). Then start/load a game and confirm the NPC's reply
  (and the narrator) come back **in the selected language** — the payload
  passes `Respond in Spanish`. UI labels stay English (only English is
  authored this phase — that is expected, not a bug). Switch back to English
  afterwards.
- Accessibility/Display/Audio tabs are stubs — confirm they do not crash.

## 7. Stability & console

- Collect the **full console** after the whole run. Acceptable: the favicon
  404, transformers model-class warnings, WebGL/GPU driver warnings. Flag
  anything else (unhandled rejections, `Failed to fetch`, errors during
  wizard/re-roll/load).
- Note any layout or contrast issues (focus ring visibility when tabbing,
  menu text on the paper background, dialogue readability, the fog over the
  scene).

## Report

Structured, per check: **PASS / PARTIAL / FAIL / BLOCKED** + evidence
(console lines, what you clicked, what happened). End with a summary of the
single most important issue, if any, plus anything that surprised you.
