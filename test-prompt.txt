# Round 10 — Runtime validation prompt (fixes + new feats)

You are validating the latest build of **Chronicles** (a visual-novel RPG built
on this Perchance generator). This round ships the **round-9 fixes** together
with **three new features** — one combined round, one report.

**Changes since round 9:**
1. **ORT proxy worker fixed** (round-9 fix, shipped now): client-side RMBG-1.4
   runs for real — expect `model ready` + `inference done` on the platform, no
   `[wasm] [object Event]`.
2. **Fog fixed** (round-9): the PixiJS canvas is now inside the scene
   container — expect a drifting haze over the frame.
3. **Sprite grounding fixed** (round-9): sprites generate on pure white with
   the ground shadow baked in; the code shadow plane was removed.
4. **NEW — Pause menu v1** (vn-rpg-spec §8.2): Esc opens a pause overlay with
   **Save / Settings / Quit to title**. Esc is dual: with a dialogue open, Esc
   closes the dialogue first (as before); with no dialogue open, Esc toggles
   the pause. **Save** writes to the AUTOSAVE slot directly (no picker).
   **Quit** asks "Save before quitting?" (Yes/No/Cancel).
5. **NEW — Speaker portraits in the dialogue box** (vn-rpg-spec §3.7): the box
   shows a **bust portrait** of whoever is speaking — NPC **and** user — in a
   frame. Portraits are generated on a **pure white background and are NOT
   background-removed** (the white is the frame backing). The portrait loads
   **async** (generated together with the sprite, never blocking it). A sprite
   **re-roll regenerates the portrait together** with the sprite.
6. **NEW — Free-form player action** (round-10 owner decision): when an NPC
   turn offers choices, a fixed **"Write your own action…"** option is always
   present. Selecting it opens an input box (player portrait + text field, max
   300 chars) where the player types their own action; submitting shows the
   player's turn with their portrait and the NPC follows up. If a turn has no
   choices, the flow is unchanged (Continue → turn ends, Leave closes).
7. **NEW — Dev context inspector v1** (tech-spec §6.4): a debug panel showing
   per-voice payload sections (NPC / narrator / user), the image prompt, visual
   description, background payload version, counts and a budget bar vs the
   ~24k window. **Off by default** — enabled by opening the generator with
   `?inspector=1` in the URL. A discreet **Dev** button appears in the HUD.

Do the checks **in order**, driving the actual UI. The AI plugins are real
here — generations take time; the loading indicators are part of what we
validate. Report everything with **console lines verbatim** (keep the `[rpg]`
logs). Before you start, read `src/README.md` for project context and the
platform↔code mapping.

## 0. Upload check (do this FIRST)

- Confirm `src/rpg/build/chunks/` contains the three.js, transformers.js and
  pixi chunks. Missing chunk → `Failed to fetch dynamically imported module`
  — STOP and report "upload incomplete".
- The local wasm asset is intentionally NOT uploaded (ONNX Runtime is pinned
  to the jsdelivr CDN via `wasmPaths`). A 404 for it is a REGRESSION.

## 1. Boot & title (quick)

- Reload. Title renders (light paper look, "CHRONICLES", NEW GAME / LOAD GAME /
  SETTINGS / CREDITS / HELP). LOAD GAME disabled without saves.
- Console at boot: `proxy worker active (… wasmPaths=CDN)` → `model ready (… ms)`.
  **NO `no available backend found` / `[wasm] [object Event]`** — the
  round-9 blocker gate.

## 2. Wizard → sprite + portrait

- **NEW GAME** → name → **Next** → click an archetype. Sprite + RMBG run
  (`model ready`, `inference done`, `cutout-cache: miss <id> → removing`).
  - The **bust portrait** also resolves **async** — it must NOT add wait time
    to the sprite (it fires in parallel). Console may show a second
    `generateImage` call for the portrait (pose `portrait`, no removal).
  - Sprite quality: clean cut-out, no mottle/dark halo, baked shadow under the
    character, black outline clean.
- Background → review → **Create**. Save created; the game scene loads.

## 3. Scene — fog + grounding (round-9 fixes regression)

- Fog drifts over the frame (two screenshots a few seconds apart — haze must
  differ). Fog must NOT block clicks and must not hurt HUD readability.
- Both characters stand grounded with the baked shadow under them; NO separate
  code-drawn shadow ellipse.
- Narrator opening plays (2-3 sentences, Leave closes).

## 4. Dialogue + speaker portraits (the big new one)

- **Talk to <NPC>**: thinking line → in-character reply → choices as buttons.
- **Portrait check:** during the NPC's turn, a **bust portrait in a frame**
  appears for the NPC. When the player submits their own action (below), the
  **player's portrait** appears instead. Only the current speaker's portrait
  shows. The narrator has NO portrait (frame hidden).
- **Free-form action:** when choices are shown, a **"Write your own action…"**
  option is always present. Select it → an input box opens with the player's
  portrait + text field. Type an action (e.g. "I draw my sword and step
  closer.") and Send → the player's turn appears with their portrait → the NPC
  replies (thinking → reply). Loop 2+ turns.
  - Edge checks: empty input does nothing (no turn submitted); Cancel closes
    the input back to the choices; Leave still always closes the dialogue;
    the 300-char cap is enforced.
  - If a turn has NO choices, the "Write your own action…" option is absent —
    flow unchanged (Continue ends the turn, Leave closes).
- **Pause menu:** while NOT in dialogue, press **Esc** → the pause overlay
  opens with Save / Settings / Quit. Press Esc again → closes. **Save** →
  "Saved." appears; the autosave slot is written (verify via Load later).
  **Settings** → the Settings screen opens from the pause; its back button
  returns to the pause menu (not the title). **Quit** → "Save before
  quitting?" with Yes/No/Cancel — Yes saves then returns to title; No returns
  to title without saving; Cancel stays.
  - Esc dual behavior: WITH a dialogue open, Esc closes the dialogue — it must
    NOT open the pause at the same time.

## 5. Re-roll regenerates sprite + portrait together

- Click **Re-roll sprite**: new seed → new sprite generation (`cutout-cache:
  miss …`, `inference done`) **and** a new portrait with the same seed.
  Console shows both generations. The sprite AND the portrait visibly change.

## 6. Warm reload / cache (regression)

- Reload WITHOUT clearing: fast, `cutout-cache: hit <id> (skip inference)`,
  no model re-download, no `inference done`. Portraits serve from the asset
  cache (no new portrait generation). Scene identical.
- Then **LOAD GAME** → same scene loads fast.

## 7. Dev context inspector (?inspector=1)

- Reload the generator with **`?inspector=1`** in the URL (keep the same page
  parameters Perchance needs). A discreet **Dev** button appears in the HUD.
- Click **Dev** → the inspector panel opens:
  - **Voice selector** (dropdown): NPC (the current NPC's name), Narrator,
    and the user's name. Switching voices swaps the sections.
  - **Sections**: named payload sections exactly as built (System, WHO YOU
    ARE, WHERE YOU ARE, CONVERSATION SO FAR for the NPC; SCENE / PRESENT for
    the narrator; NAME / APPEARANCE / BACKGROUND for the user). The
    **CONVERSATION SO FAR** section is highlighted as **summarizable**; all
    others are marked **never summarized**.
  - **Counts + budget bar**: per-section char counts and a bar vs 24,000 chars
    with the window-summary trigger marker.
  - **Copy payload** copies the selected voice's full instruction.
  - **Refresh** re-reads the payload.
- Report what each voice shows and whether the button/panel render correctly
  with `?inspector=1` (and confirm the button is ABSENT without the param).

## 8. Stability & console

- Collect the full console. Acceptable: favicon 404, transformers
  model-class warnings, WebGL/GPU driver warnings. Flag anything else
  (unhandled rejections, `Failed to fetch`, `[wasm]` errors, wizard errors).
- Letterbox frame, HUD readability, sprites a reasonable size. **Screenshot**
  the scene with a dialogue open (portrait visible) and include it.
